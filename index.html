Catatan keamanan

Login aplikasi memakai Firebase Authentication. Email yang digunakan Firebase bersifat internal dan tidak ditampilkan pada form login; pengguna tetap masuk memakai username + password seperti aplikasi lama.

Upload Data Warga (JSON)

Fitur ini memudahkan Anda menambah banyak data warga secara sekaligus dengan mengunggah file berkas format JSON.

Contoh Format Isi File JSON: 

[
  { "nik": "1801012345670001", "nama": "Ahmad Subagyo", "rt": "RT 01" },
  { "nik": "1801012345670002", "nama": "Budi Santoso", "rt": "RT 02" }
]

Tersedia sebagai Aplikasi Web Siap Instal

A. Panduan Instalasi di HP Android / Chrome:

  1. Tekan tombol "Instal Aplikasi" di bawah ini atau di banner bagian atas.
  2. Jika tombol tidak muncul, tekan menu titik tiga (⋮) di pojok kanan atas browser.
  3. Pilih menu "Tambahkan ke Layar Utama" atau "Instal Aplikasi".

B. Panduan Instalasi di iPhone / iPad (Safari):

  1. Buka tautan web ini menggunakan browser Safari.
  2. Tekan tombol Bagikan (Share) di bagian bawah layar.
  3. Pilih menu "Tambahkan ke Layar Utama" (Add to Home Screen).
